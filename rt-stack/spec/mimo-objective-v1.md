# MIMO 低频目标函数与对比验收规范 v1.1（mimo-objective-v1，默认参数已冻结）

> 状态：**SPEC-ONLY（2026-11-21，v1.1 按用户/GPT 复审冻结默认参数并补 holdout 否决条件）**。约束对象 = **设计/评估层**（G 的目标函数、约束、指标、对比矩阵）。
> **不修改现有求解器**（`modal-design/src/{solve,regularize,validate}.rs` 保持不动）：本规范只定义“优化什么、约束什么、怎么判”，
> 求解器实现仍按现有 CGLS + λ/CV + 白名单 + holdout 隔离执行。
> 作者：Lead；对应需求：USER-REQUIREMENTS #19/#20/#27/#29/#42/#43；mimo-t6.md（T6-M）为实测验收门。

## 0. 边界（必须先声明）

1. **前馈系统**：G 是开环因果 FIR，只能通过**空间干涉**降低设计点上的模态声压，**不能提供真实模态阻尼**。
   → 任何 `E_decay` 都**只报告、不进入优化目标**（EDC@100ms、RT20→RT60 均为报告观察量）。
2. **不承诺“消除全部驻波”**；目标可声明为“在给定 effort/headroom/因果约束下的模态带残余最小化”。
3. **不预设控制能力**：40–60 Hz 是否只有 SUB1 可控、中高频五路是否独立，**必须由真实 H 的 SVD/相干性决定**（见 h-diag 工具）。
4. **provenance fail-closed**：合成/dry-run H 或 G（含历史 synthetic 指纹）**一律拒绝**进入设计/评估；无法确证真实测量 → `UNPROVEN`。
5. **holdout 隔离**：任何权重、λ、白名单、target、D、参数选择**只能用 design 点**；holdout 只用于验证，违反即 FAIL。

## 1. 记号

- 执行器：N = 5（`FL,FR,SL,SR,SUB1`；HFL/HFR 不参与低频矩阵）。
- 测点：M（design 点 + holdout 点分开）。
- 复数传递矩阵 `H(f) ∈ C^{M×N}`（由 h-diag 从真实多点测量重建，含相位/延迟）。
- 冻结基线后 `H_eff(f) = H_raw(f)·P_post(f)`（P 只乘一次）。
- 设计变量：因果 FIR `g[j][i][t]`，`G(f) = δ_D·I + Σ_t g[t] e^{-j2πft/fs}`，t=0..L_G−1，L_G ≤ 4096，D 为公共整数延迟。
- 参考激励 `s_ref(f) ∈ C^{N}`：**冻结声明**（默认：5 个参与通道各 1.0 的复数单位激励；用于对比时必须与 baseline 相同）。
- 声压：`P(f) = H_eff(f)·G(f)·s_ref(f)`。`P_before` = `G = δ_D·I`（preserve 基线），`P_after` = 设计后的 G。

## 2. E_modal（主目标，v1 默认策略）

### 2.1 模态带

`B_k`：1/3 oct 中心频率 **40, 50, 63, 80, 100, 125, 160, 200 Hz**（8 带），每带边界按 1/3 oct 标准（±1/6 oct）。
频带内逐频权重 `w_f`：默认 1.0（等权）；可选按频率分辨率归一（实现须声明）。

### 2.2 归一化残余能量（关键：用比例，不用绝对平方和）

```
R_k = ( Σ_{f∈B_k} w_f |P_after(f)|² ) / ( Σ_{f∈B_k} w_f |P_before(f)|² )
```

- `R_k ∈ [0,∞)`；`R_k < 1` 表示该带残余下降；`R_k > 1` 表示**恶化**（必须报告）。
- 分母为 0/近零（该带无有效基线能量）→ 该带标 `N/A`，**不参与** 加权求和（并按数量报告）。

### 2.3 带权重 α_k（能量加权 + 权重上下限）

```
E_k   = Σ_{f∈B_k} w_f |P_before(f)|²        # 该带基线能量（仅 design 数据）
x_k   = E_k / mean_k(E_k)                    # 相对能量
a_k   = clamp(x_k, α_min, α_max)             # α_min = 0.5, α_max = 2.0（默认）
α_k   = a_k · K / Σ_j a_j                    # 归一化，使 Σ_k α_k = K（K = 有效带数）
```

- **默认模式**：能量加权 + 下限 0.5 / 上限 2.0（防止最响模态垄断，也防止弱带被忽略）。
- **对照模式**：`α_k = 1`（八带等权）。两种模式都必须在报告中给出（默认模式决定设计，等权模式作对照）。
- 权重**只由 design 点计算**；holdout 不参与。

### 2.4 目标

```
E_modal = Σ_k α_k · R_k        # 最小化
```

**v1 不做 minimax 主目标**；但必须独立报告：

```
R_max = max_k R_k              # 最差模态带，独立验收指标
```

## 3. 执行器代价 E_effort（约束 + 报告，v1 不做罚项主导）

```
E_effort = Σ_i Σ_t g[i][t]²         # 全部 FIR 系数能量（含非对角路径）
```

- v1 把它作为**硬约束**而非主目标：`E_effort ≤ E_effort_max`（由 headroom/增益帽推导，见 §4），超限即 INFEASIBLE；
- 同时报告：`E_effort / E_effort_baseline`（相对 δ_D·I 的能量比）、每路径最大增益、峰值预测；
- 后续版本可改成 `J = E_modal + λ_e·E_effort`，**v1 不改求解器**。

## 4. 约束（硬门，违反即 INFEASIBLE/FAIL）

| 约束 | 值/口径 |
| --- | --- |
| 因果性 | `g` 支撑 t=0..L_G−1，公共 D 固定；禁止 IFFT→截断破坏因果 |
| 长度 | `L_G ≤ 4096`；`L_F = L_A + L_G + L_P − 2 ≤ 4096` |
| 路径增益帽 | 每修正路径默认软帽 ≤ −6 dB；显式放宽 ≤ +6 dB；系数实算 ≤ 帽 + 2 dB |
| headroom | 预测峰值 ≤ −6 dBFS；**实测**峰值 ≤ −1 dBFS |
| 频带上限 | 模态处理 ≤ 200–300 Hz（中高不用 MIMO） |
| 参与者 | 固定 5：FL/FR/SL/SR/SUB1；HFL/HFR 显式排除 |
| 采样率 | 48 kHz（96 kHz 需单独声明与验证） |
| holdout | 只验证，不参与任何选择 |

## 5. 报告指标（全部必须输出）

1. 每带：`R_k`（归一化残余）、**绝对能量变化 dB**（`10log10(after/before)`）、该带基线能量 `E_k`；
2. `E_modal`（默认权重 + 等权对照各一份）、`R_max`、以及 `argmax_k`；
3. **能量迁移检测**：若某带 `R_k > 1 + ε`（默认 ε = 0.05, 即恶化 >0.2 dB）且其它带下降 → 标 `ENERGY_MIGRATION`，**不得**在总结里只报总能量下降；
4. EDC@100ms、RT20→RT60、EDC 曲线：**报告观察量**（低置信须标注），不参与优化；
5. effort：`E_effort`、相对基线比、每路径最大增益、预测/实测峰值；
6. 求解器诚实字段：每列迭代数/残差/收敛标记；λ、CV 结果、白名单类型、holdout 一致性；
7. provenance：H/G 来源文件、sha256、真实/合成标记（合成一律 UNPROVEN）。

## 6. 基线对比矩阵（真实 H 到手后必须四组都跑）

| 组 | G | 基线 P | 说明 |
| --- | --- | --- | --- |
| B0 RAW | δ_D·I | 仅 P_post 基础（无 PEQ 校准） | 原始系统 |
| B1 PEQ-only | δ_D·I | P_post 含单通道 PEQ（现有 legacy 拟合） | 传统 EQ 上限 |
| B2 MIMO | 设计 G（λ=0 或极小） | 同 B1 | 纯 MIMO |
| B3 MIMO+reg | 设计 G（λ 由 design-CV 选） | 同 B1 | 推荐配置 |

### 6.1 判据 A：性能改善（与 holdout 分开判）

```
Δ_MIMO-PEQ = E_modal(B1) − E_modal(B2/B3)
要求： Δ_MIMO-PEQ ≥ δ = 1.0 dB
```

- 必须基于**同一口径的 measured 模态能量指标**（§2 的 `E_modal`），**不得**用某频点峰值代替；
- `R_max` 同时要求改善（`R_max(B3) < R_max(B1)`），作为独立观察；最差模态未改善要在结论里点名；
- 不满足 δ → 独立结论 `MIMO_NO_GAIN_VS_PEQ`（不得被"总能量下降"掩盖）。

### 6.2 判据 B：holdout 一致性（空间泛化，独立判）

```
C = (达到预期改善方向的有效 holdout 点数) / (有效 holdout 总数)
要求： C ≥ 0.50   且   无严重反向恶化
```

- **严重反向恶化 = 独立 FAIL（一票否决）**：任一有效 holdout 点上，任一模态带实测
  `10log10(after/before) > +3.0 dB`（即能量翻倍级恶化）→ `HOLDOUT_SEVERE_REGRESSION`，**即使 C ≥ 0.5 也 FAIL**；
  该阈值默认 +3.0 dB，可显式放宽/收紧但必须声明并冻结；
- **有效 holdout 数 < 3 → `INCOMPLETE`**（不是 PASS，也不是 FAIL）；
- **统计诚实性**：3 个 holdout 时 C ≥ 0.5 实际等价"至少 2/3 点同向"，这只是**初步空间泛化验证**，
  **不得**表述为"统计显著/充分验证"；报告中必须写 holdout 点数与该项限制。

### 6.3 状态独立性（禁止互相掩盖）

以下状态**各自独立输出**，任一项不能由其它项的好坏抵消：

| 状态 | 含义 |
| --- | --- |
| `ENERGY_MIGRATION` | 局部带恶化（> ε=0.05 相对恶化）而总能量下降 |
| `MIMO_NO_GAIN_VS_PEQ` | Δ_MIMO-PEQ < δ |
| `HOLDOUT_SEVERE_REGRESSION` | 任一 holdout 出现 > +3.0 dB 带级恶化 |
| `WORST_MODE_NOT_IMPROVED` | `R_max` 未改善 |

- 若 B2/B3 不能显著优于 B1 → 如实写"MIMO 相对 PEQ 无增益"，不得美化。

## 7. 诚实状态机

`PREDICTED_PASS / PREDICTED_PARTIAL / INFEASIBLE / INCOMPLETE / UNPROVEN`：
- 只有 measured（应用后复测 + holdout）可写 PASS；
- `applied=false` / `measured=false` 必须显式；
- synthetic 数据 → `UNPROVEN`；
- T6-M 的 I/T20 ≥15% 属**观察值**，不参与 PASS/FAIL（mimo-t6.md §8.2.1）。

## 9. 冻结默认参数（v1.1，2026-11-21 用户/GPT 确认）

| 参数 | 值 | 说明 |
| --- | --- | --- |
| `α_min` / `α_max` | **0.5 / 2.0** | 能量权重上下限（相对平均），防止最响模态垄断、防止弱带被忽略 |
| `ε`（能量迁移） | **0.05** | `R_k > 1+ε`（≈ +0.2 dB 恶化）即标 `ENERGY_MIGRATION` |
| `δ`（MIMO vs PEQ） | **1.0 dB** | 判据 A：`Δ_MIMO-PEQ ≥ 1.0 dB`（同口径 measured 模态能量） |
| Holdout 一致性 `C` | **≥ 0.50** | 判据 B；3 点时为 2/3，仅初步泛化 |
| 严重反向恶化 | **> +3.0 dB 任一 holdout 任一模态带 → 独立 FAIL** | 一票否决，不受 C 影响 |
| 有效 holdout 数 | **< 3 → INCOMPLETE** | 不判 PASS/FAIL |
| 数据性质 | **全部判定基于 measured** | predicted 只能作 honest-check |

以上数值冻结；任何修改必须升版本并在证据中写明理由。其余（`w_f`、`s_ref`、`λ` 扫描范围、增益帽放宽）保持可配但必须在报告中声明。

## 10. 统计诚实性（必须写进报告）

- 3 个 holdout 点的 50% 一致性**只能称"初步空间泛化验证"**，不得称"统计显著/充分验证"；
- 报告必须列出：holdout 点数、每点每带的 `R_k` 与绝对 dB 变化、被否决的具体点/带（若有）；
- 设计点（design ≥6）与 holdout（≥3）的划分必须在测量前**预注册**并冻结，禁止事后挑选 holdout。

## 11. 目标可达性与物理边界（v1.2 增补，2026-11-21）

**必须先区分两件事**：

| 现象 | 物理含义 | 开环 FIR 能否做到 |
| --- | --- | --- |
| 该测点稳态声压峰被压低 | 空间干涉抵消（频域） | ✅ 可以（设计点） |
| 瀑布图“初始能量”降低 | 激励耦合降低 | ✅ 通常会 |
| **EDC 尾部斜率 / T20 变短** | 房间模态**极点**（真实阻尼）改变 | ❌ **开环 FIR 不能移除房间极点**，只能通过零点有限整形瞬态包络 |
| 房间真实模态阻尼增加 | 需要改变声学耗散（吸声/结构）或闭环主动阻尼 | ❌ 不在本系统能力内 |

因此：
1. **v1 的目标是“设计点模态带稳态残余最小化”（`E_modal`），不是“缩短 T20”**；
2. 求解器完美完成 `E_modal` **不保证** T20/EDC 改善；任何“T20 显著变短”的声称必须来自 measured 且写明机制；
3. 若用户真正目标是缩短低频衰减时间，需要另立研究（改变耦合/摆位/吸声，或闭环主动阻尼），**不能靠增加 FIR 长度或多点数量解决**；
4. 报告必须把“初始能量下降”与“衰减斜率变化”分开：用 EDC 在 0–100 ms（初始）与 −5…−25 dB 斜率（衰减）两段分别报告；
5. **T20 未改善 ≠ FIR 无价值**：降低模态初始能量/该点稳态声压是**独立且有物理意义**的收益，只是不等同于“房间阻尼增加”；两者必须分开陈述，不得互相否定。
