## 5. v11 板窗必验（先 mute/默认路径回归，再 12k 离线两臂 / AES67 / T70 / 重启持久性）

前置：MOTU/功放物理静音（CueMix 不改）；窗口内不启停 systemd 之外的进程；48k（禁 176.4k/192k）。
完整步骤/判据：rt-stack/evidence/release-v11/BOARD-WINDOW-2026-11-20.md（明日板窗执行单）。

1. **安装后 mute 验收**：host active + SAFE_MODE=mute、healthz=200、06 verify V1–V10 PASS；
   host 运行报告 `scheduler.dsp_cpus=[4,5,6,7]`；IRQ 58/56/57 → 1/2/3（均 A53，irqbalance inactive）。
2. **默认路径回归（v11 关键判据）**：既有（不含 [mimo12k]）配置启动 host，报告 `mimo12k.enabled=false`，
   渲染/实时行为与 v10 一致；失败即回滚 v10，12k 支路不得在默认路径产生任何输出差异。
3. **12k 保守变体离线两臂（先不真实时）**：用 provenance guard 真实 H 设计的 G/12k 保守变体（证据
   release-v11/artifact/mimo12k-fixtures 与直通 plan），先 `[sink]` 离线渲染两臂：直通臂 vs 修正臂，
   复核 rel L2(vs f64 参考) ≤2e-3、max_abs、非 participant 容器=0、报告 mimo12k 段（taps/ds ys/g_sha256/mapping）；
   若授权与时间允许再测真实时（AES67/静音链路），**不声称声学改善**。
4. **AES67 静音链路**：按 v9/v10 接线（aes67_transport=userspace + SDP + 静默 run），复核
   transport=userspace/pacing=userspace-block-timer/clock=usrvclock/ptp=not-wired/loss_events=0；真实网络待 H16。
5. **T70 Web 认证初始化**：按 web/docs/T70-* 与 daemon auth_file 口径初始化（G1/G2 未修，见 §6）。
6. **重启持久性**：`systemctl reboot` 后复核 host/daemon/keeper active、SAFE_MODE=mute、healthz=200、
   IRQ 亲和恢复、release/current → @RELEASE_ID@、last-good 指向 v11；失败回滚 v10。
7. 结束还原：mute/healthz 200；CueMix 0 写；/dev/shm 清理。

## 6. 依赖与边界

- 板上需 python3、systemctl、tar、sha256sum；上传包不联网。
- 所有板端动作 **NOT_RUN**（安装/systemd/真实 ALSA/MOTU 播放/RT/IRQ 持久化/浏览器/AES67 真实网络与 PTP/回滚演练）。
- AES67 userspace 时钟为进程内 UsrvClock，**非 PTP**（报告显式 ptp=not-wired）。
- 12k 支路仅离线/预测证据（P=3 无 holdout）：不得当板端实时/声学改善证据；默认路径不变是构建期 qemu 对照结论。
- Web auth G1/G2 仍未修：daemon 仍不读取/持久化 auth_file；T70 Web 认证初始化前需按证据确认现状。
- 校准 synthetic 的测量=stage fake、设计=synthetic_offline、apply=离线合成 ack：不得当 T67/T68/T6 真实证据。
- 禁 CamillaDSP/旧 C unit 作任何回退；授权窗口 JSON 与 audio_off/S1/soak 口径见 deploy/README.md §1/§3。
