## 5. v10 板窗必验（先 mute healthz/verify，再路线 B / AES67 / T70 / 重启持久性）

前置：MOTU/功放物理静音（CueMix 不改）；窗口内不启停 systemd 之外的进程；48k（禁 176.4k/192k）。
完整步骤/判据：rt-stack/evidence/release-v10/BOARD-WINDOW-2026-11-20.md（明日板窗执行单）。

1. **安装后 mute 验收**：host active + SAFE_MODE=mute、healthz=200、06 verify V1–V10 PASS；
   host 运行报告 `scheduler.dsp_cpus=[4,5,6,7]`；IRQ 58/56/57 → 1/2/3（均 A53，irqbalance inactive）。
   **注意**：板端已装 /etc/tspi-rt-stack/rt-host.env 仍为 TSPI_HOST_DSP_CPUS=2-5（04 不覆盖），
   窗口内改为 4-7 或删除该行后重启 host，再复核（预算 1–2 min；改前记录原值，失败回滚）。
2. **daemon 空闲 CPU 复核**（v10 新）：部署后 `top -b -n2 -d 5 -p $(pidof tspi-rt-daemon)` 应在 0.1% 量级
   （v9 前 92.5% → task-245 补丁 0.03%）；同时 `systemctl stop tspi-rt-daemon` 不应挂起（wake 契约）。
3. **路线 B（G-4096 真·实时两臂对比，需出声授权）**：v10 默认 auto → partitioned；G-4096 下应
   effective=partitioned、main_cpu∈4-7、workers=0；1500 块静音 duplex 0 xrun；engine=direct 对照（仅小窗口）
   复现 underrun 即证明引擎差异。**不静默降级**：显式 engine=partitioned 失败必须 fail closed。
4. **AES67 静音链路**：按 v9 接线（aes67_transport=userspace + SDP + 静默 run），复核
   transport=userspace/pacing=userspace-block-timer/clock=usrvclock/ptp=not-wired/loss_events=0；
   真实网络/IGMP/电平仍属 H16 到货后项。
5. **T70 Web 认证初始化**：按 web/docs/T70-* 与 daemon auth_file 口径初始化（v9 未修 G1/G2，见 §6）；
   本包不含 web dist，Web 侧若需替换按 web/scripts/install-device.sh 单独上传。
6. **重启持久性**：`systemctl reboot` 后复核 host/daemon/keeper active、SAFE_MODE=mute、healthz=200、
   IRQ 亲和恢复、release/current → @RELEASE_ID@、last-good 指向 v10；失败回滚 v9。
7. 结束还原：mute/healthz 200；CueMix 0 写；/dev/shm 清理。
