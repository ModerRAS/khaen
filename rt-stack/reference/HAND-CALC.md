# HAND-CALC — T03 手算 impulse/卷积向量（P0，独立于任何 Rust/rt-check）

2026-11-16 · rt-reference（WBS T03 / team task-23）。写域：`projects/tspi-audio-dsp/rt-stack/reference/`。

本文是 [SPEC.md](SPEC.md) 数学模型的**手算可复现证据**：每个小用例的全部系数、输入、输出都小到可以人算，
数值全部取整数或二进制可精确表示的分数（0.25/0.5/1.5…），因此正确结果在 binary64 中**逐位精确**，
后续 direct/FFT 实现（T07/T08）与 f64 参考比较时不允许出现任何误差。

机器校验：本文件里的 fenced JSON 块（`handcalc` / `handcheck` / `handtrap`）由
`tools/verify_reference.py` 解析，用**独立于生成器的精确有理数逐样本直接卷积**复算，再与
`fixtures/cases/*.json` 对照。命令与 exit code 记在 `evidence/T03/manifest.json`。

- `handcalc`：给全 input/expected 的完整手算用例；块内 expected 必须与 fixture 的 expected 完全一致。
- `handcheck`：只抽若干 (container, n, value) 样本的手算点检（大矩阵用例用）。
- `handtrap`：手算“错误实现”会得到什么值，用来证明测试能抓到 circular 混叠 / 行列顺序错误。

手算符号约定（与 SPEC §2 一致）：`*` 为线性卷积；`δ_k` 是第 k 个 tap 为 1 的单位冲激；
`z^{-1}` 为 1 样本延迟；`P=diag(p_j)` 作用在输出行，`A_i` 作用在输入列；`G = δ_D I + g`；
`L_F = L_A + L_G + L_P − 2`（D 计入 `L_G`），离线输出长度 `L_out = L_in + L_F − 1`（含全部尾）。

## H4 · C04 P/G 级联的尾（tail）：G=[1,2]，P=[1,−1,2] ⇒ F=[1,1,0,4]

`g=[[[0,2]]]` 表示 g 的 tap0=0、tap1=2；`δ_D I`（D=0）给 tap0 加 1 ⇒ `G = [1, 2]`，`L_G=2`。
`P = [1, −1, 2]`，`L_P=3`。先手算级联 FIR `F = P * G`（逐 k 表）：

| n | P 项贡献 | F[n] |
|---|---|---|
| 0 | P0·G0 = 1·1 | **1** |
| 1 | P0·G1 + P1·G0 = 1·2 + (−1)·1 | **1** |
| 2 | P0·G2 + P1·G1 + P2·G0 = 0 + (−1)·2 + 2·1 | **0** |
| 3 | P1·G2 + P2·G1 = 0 + 2·2 | **4** |
| 4 | P2·G2 = 0 | 0 |

`F=[1,1,0,4]`，长度 `L_F = L_A+L_G+L_P−2 = 1+2+3−2 = 4`。
输入 `x=[1,1]`，`y = F * x`：

| n | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| y[n] | F0x0=1 | F0x1+F1x0=2 | F1x1+F2x0=1 | F2x1+F3x0=4 | F3x1=4 |

`L_out = 2+4−1 = 5`，尾长 3（当 x 结束时 n=2..4 仍有非零）。注意 F[2]=0 仍然占长度，
输出长度由公式而不是“最后一个非零”决定。

## H7 · C07 factorized 与 fused 等价（offdiag + 尾 + D=1）

`g=[[[], [0.5]], [[0.25], []]]`，D=1 ⇒

`G = [[z^{-1}, 0.5], [0.25, z^{-1}]] = [[[0,1], [0.5]], [[0.25], [0,1]]]`，`L_G = 2`。

## H11 · C04 圆周卷积陷阱：FFT 长度不足会混叠

同一个 `F=[1,1,0,4]`、`x=[1,1]`，若把 F 与 x 做成 **N=4 的圆周卷积**（FFT 长度 4，没有
zero-pad 到 `len(x)+L_F−1=5`）：

`y_c[n] = Σ_{k=0}^{3} F[k]·x[(n−k) mod 4]`：

- `y_c[0] = F0x0 + F3x1 = 1 + 4 = 5`（把 y[4] 的尾卷回 n=0）
- `y_c[1] = F0x1 + F1x0 = 1 + 1 = 2`
- `y_c[2] = F1x1 = 1`
- `y_c[3] = F3x0 = 4`

⇒ `[5,2,1,4]`，与线性结果 `[1,2,1,4,4]` 不同，且丢了尾。SPEC §3.4 因此要求频谱相乘前
zero-pad 到至少 `L_x + L_F − 1`（或等价保证线性卷积）。handtrap 块把这个错误值固化，供测试反断言。

## H12 · C14 输入侧 FIR 作用于列：A=diag([0,−1], [2])

SPEC/CPU 预算：`F_ji = p_j * G_ji * A_i`，即输入侧 FIR 作用在**列**（i），输出 P 作用在**行**（j）。
本用例 `a0=[0,−1]`（1 样本延迟 + 反相）、`a1=[2]`；`G=[[1,2],[−1,1]]`（同 H3）、`P=I`。
