# 技术方案

状态：**已确认（2026-11-22）**。实施计划见同目录 `tasks.md`，待确认。确认前不改播放引擎、不重新生成房间系数、不进房间。

需求见同目录 `requirements.md`。本方案只增加皇帝位这一条衰减设计。现有幅度填谷求解器、第一种模态均衡、补谷和播放卷积的数值语义在装得下时保持原样。

## 1. 结论

新求解器按声道独立设计。主喇叭固定是该声道自己，低音效果声道的主喇叭是 SUB1。从喇叭是用户从已测喇叭里勾选的子集，默认不自动勾选。代价函数在时域：主喇叭与选中的从喇叭合成一条脉冲响应，去贴近一条短目标，focus 窗加大尾巴上的误差权重。支援频段上沿可调，未设置时 150 Hz，高于 150 Hz 拒绝。

播放仍走现有 `[mimo12k]` 侧路：plan 保持恒等，长滤波器不写进 plan 路径。抽头可以加长。加长增加的是系数能作用的时间跨度，不是听感延迟。跨度盖不住脉冲响应里仍高于噪声底的那段尾巴时，加高抽头上限；分区数因此超过 256 时，连分区上限一起加高。加高之前，设计标为不可播放。

采集保持 48 kHz。本路径的扫频从 20 Hz 到 500 Hz，不扫到 20 kHz。12 kHz 只在设计域和侧路播放里使用，由 48 kHz 测量抽取得到。

```mermaid
flowchart LR
  mic["48 kHz 扫频 20–500 Hz<br/>皇帝位一只麦"] --> gate["噪声底以上的尾巴<br/>T30 或 T20"]
  gate --> solve["按时域 focus 求解<br/>主喇叭固定，从喇叭为用户所选"]
  solve --> fir["12 kHz 分区 FIR<br/>跨度盖住可测尾巴"]
  fir --> play["mimo12k 侧路<br/>听感延迟不随抽头变长"]
```

## 2. 求解

播放时直通已经送出主声的延迟副本。侧路系数是加在上面的修正，不是替换主声的整段滤波器。每个声道在 12 kHz 域里最小化：

```text
p̂ = h_p ∗ (δ_D + g_pp) + Σ_{s∈S} h_s ∗ g_sp
|| W (p̂ − d) ||² + λ Σ_{s∈S} ||g_sp||²
```

`h_p`、`h_s` 是已经用播放同一条抗混叠低通抽到 12 kHz 的脉冲响应。`δ_D` 是 `D12` 个样本的纯延迟，对应直通在低频上的那一截。`g_pp` 和 `g_sp` 就是侧路要卷积的系数。对角线上再写一个 `δ_D` 会把主声低音放两遍。

`d` 保留 `h_p ∗ δ_D` 里主峰之后 `t_keep` 以前的样本，其后为 0。缺省 `t_keep = 20 ms`。`W` 在这段以前为 1，其后为 `w_tail`。缺省 `w_tail = 10`。`λ` 只罚从喇叭，缺省按各从喇叭自身能量归一后取 `λ0 = 0.01`。这三个数写入报告，不拿来搜索「预测衰减更好」的组合。

`g_pp` 和所有 `g_sp` 在上沿以上的频率分量为 0。上沿缺省 150 Hz，可调低，大于 150 Hz 拒绝。未选中的从喇叭不进入求和，系数精确为 0。没有脉冲响应的喇叭不能被选为从喇叭。从喇叭集合允许为空，这时只求主喇叭自己的尾巴修正。

这不是路线图 §3.5 的频域幅度目标，也不调用 `proto_g.py` 的填谷平滑。旧的 constrained-12k 系数（sha `b56b3426…`）按 sha 识别后拒绝标成这条设计。

## 3. 算法步骤

后面的实现按这个顺序做。跳过一步就会回到用幅度或外推衰减报成功的旧路径。

1. 采集用 48 kHz、20–500 Hz 扫频。皇帝位一只麦，每只候选喇叭一条脉冲响应。不扫到 20 kHz。
2. 在控制频段做能量衰减曲线。到不了 −25 dB 点就拒绝这次测量。到得了 −35 dB 点，日后复测用 T30；只能到 −25 dB 点就用 T20。这个选择只决定复测看哪个数，不决定滤波器多长。
3. 用播放侧路同一条抽取低通把脉冲响应抽到 12 kHz，并记下 `resamp_taps` 和 `D12`。不在 48 kHz 上求完滤波器再把系数抽下去。
4. 可测尾巴是主峰到控制频段包络落入噪声底的时间。focus 窗的终点是这段尾巴，不是外推出来的 T20 或 T30 秒数。
5. 抽头数等于 `D12` 加上这段尾巴所需的 12 kHz 样本，使有效修正支撑不短于可测尾巴。有效支撑是 `(抽头 − D12) / 12 kHz`。分区数 `Q = ceil(抽头 / (块长48 / 4))`。抽头超过 `MIMO12K_MAX_TAPS`，或 `Q` 超过 256，设计标为不可播放，先放宽对应上限。块长 128 时 8192 点仍在 256 个分区内。块长 64 时超过 4096 点就要同时放宽分区上限。听感延迟不随抽头变长。
6. 按第 2 节的最小二乘，逐个声道求 `g_pp` 和选中的 `g_sp`。进入代价之前，脉冲响应先限制在下沿到上沿，所以被压的是这一段的尾巴。带通是零相位的，脉冲放在变换缓冲中间，振铃留在两侧空白里，不折进尾巴。下沿以下的基不加。主峰之后的保留段仍用时域误差。尾巴上的误差只累计下沿到上沿的汉宁谱，权重仍是 `w_tail`，复数最小二乘，不逐频点去贴一条幅度曲线。一套音箱一起放时，按到座位的实测路程差对齐，声速 343 m/s，早到的音箱在直通和侧路上补同一段。这段延迟不写入系数，也不代替 `D12`。口头估算的距离只用来看数量级，不进测量、不进播放。低频峰比自己的直达声更晚，那是这只音箱的低频建立，不拿来当作音箱之间的延迟。
7. 取这次播放里全部音箱的最高预测正增益 G dB。G 不超过 20 时，全部音箱先做同一个预衰减 −G dB，系数保持原样。没有正增益时预衰减为 0。各音箱一起衰减，相对声压不变。G 超过 20 则整套拒绝，不削顶后报成功，也不让其余音箱各用各的预衰减。+20 dB 对应的共用预衰减就是 −20 dB。这份预衰减加在全部数字输出上，防止数字削波。
8. 导出的是侧路修正系数。报告写明：单座位、上沿、`t_keep`、`w_tail`、`λ0`、从喇叭集合、可测尾巴、抽头、`Q`、`Δsys`、预定的 T20 或 T30、可播放或不可播放。离线卷积只记成预测。

复测时麦克风放回设计时的位置。对消半径按本次上沿估计：80 Hz 约 0.4 m，40 Hz 约 0.9 m。头偏出这个半径不算这次通过，也不因此再开一轮求解。

实现时不要做这几件已经否掉的事：

- 用 `|Hg − T(f)|` 或 1/6 oct 幅度平滑当代价。
- 用外推的 T20、T30 或 T60 当作抽头长度。
- 把 4096 点的 341 ms 跨度当成听感延迟。听感延迟是重采样群延迟加 `4·D12`，现约 12.0 ms。
- 因为只有一个麦克风就拒绝从喇叭交叉项。
- 用预测衰减、系数 sha 或数字对拍把衰减标成通过。
- 复测没变短或不可证伪之后，改 `λ`、加抽头或重算矩阵再报一轮。

## 4. 播放引擎

`[mimo12k]` 已经要求 plan 的 G、P 和基线延迟与侧路一致，并且产物参与者顺序等于 plan 角色顺序。本方案继续用这道门，不把 12 kHz 系数塞进没有逐路径采样率的 plan。

侧路是分区 FIR。分区大小是 48 kHz 块长的四分之一，分区数 `Q = ceil(抽头 / 分区大小)`，现有分区上限 256。听感延迟 `Δsys` 只包括两段重采样群延迟和预延迟 `D12` 换算回 48 kHz 的部分，公式是 `decim_delay + interp_delay + 4·D12`。抽头变长不改变这个数。当前重采样 95 点、`D12 = 120` 时，`Δsys` 是 574 个 48 kHz 样本，约 12.0 ms。

抽头决定的是另一件事：系数跨度 `g_span = 抽头 / 12 kHz`，有效修正支撑再减去 `D12`。4096 点的跨度是 341 ms，有效支撑约 331 ms。块长 128 时，分区上限允许加到 8192 点，跨度 683 ms，`Δsys` 仍约 12 ms。块长 64 时，4096 点已经把 256 个分区用满，再加长就必须同时提高分区上限。

滤波器要盖住的是控制频段里仍高于噪声底的尾巴，不是外推的 T20/T30。跨度不够时提高 `MIMO12K_MAX_TAPS`；因此超过 256 个分区时，同时提高分区上限。直通引擎自己的 4096 点上限不跟着放宽。生产 soak 结束前不把改过的引擎装到 sender-host、N150 或 MOTU。

运行时整条输出仍是 48 kHz。一块 128 点的 48 kHz 输入同时走两条支路，在同一块里相加：

```text
直通:  x ────────────── z^-Δsys ──────────────┐
修正:  x ─抗混叠─ ↓4 ─ G(12 kHz 分区 FIR) ─ ↑4 ─┤
                                              (+) → 48 kHz
```

128 点正好抽出 32 点，等于侧路的一个 12 kHz 块，所以两路按同一块时钟前进，不用另起一条时间线。直通保留全频段。修正支路先被抗混叠滤到 6 kHz 以下，求解再把从喇叭限制在所选上沿以下。高于上沿的声音只来自被延迟了约 12 ms 的直通。`Δsys` 必须同时加在直通上，两路才在同一个 48 kHz 样本上对齐。

## 6. 测试与安全

离线用合成的单模态脉冲响应验证：上沿 150 Hz 与 80 Hz 都能求解，151 Hz 被拒绝；没选从喇叭时从路径为零，主修正仍然可求；选中的从喇叭在上沿内有系数，上沿以上的主修正和从修正都为 0。导出的对角系数是 `g_pp`，不再包含一个 `δ_D`。衰减曲线到不了 −25 dB 时拒绝；只到 −25 dB 时指标为 T20，到得了 −35 dB 时指标为 T30。抽头长度等于可测尾巴而不是外推 T20。旧填谷 sha 不能标成衰减设计。抽头加长后 `Δsys` 仍等于重采样延迟加 `4·D12`。块长 128、抽头 8192 仍在 256 个分区内；块长 64 要超过 4096 点时，分区上限一起放宽，否则标为不可播放。

正增益配等量的全局预衰减，下限 −20 dB。预测增益超过 +20 dB 则拒绝，不削顶后报成功。房间测量和部署不在本方案内。
