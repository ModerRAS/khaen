泰山派3M（RK3576）· Debian 12 · 音频 DSP 设备

忘记密码 / 使用 token（恢复兜底）

token 保留为恢复/CLI 兜底，填在下面可直接登录（不需要密码）。默认在设备 /etc/khaen-audio-web/config.toml；查看：

sudo khaen-audio-web --config /etc/khaen-audio-web/config.toml --print-token
sudo journalctl -u khaen-audio-web -b | grep -i "token"

mock 模式 token 为 mock-token。管理密码需在首次打开时设置；已设置后不能重复 setup。

仅限局域网管理；所有 API 除 /healthz 外均需认证，写操作带 CSRF 防护。

首次设置管理密码

首次打开 Web：设置管理密码后立即登录。token 仍保留为恢复/CLI 兜底。

首设无认证是局域网便利与安全的折中：请仅在可信网络完成设置；设置后写 /etc/khaen-audio-web/auth.json（0600，Argon2id）。
